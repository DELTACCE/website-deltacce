# DELTA — Website Codebase
### Data Oriented Thinkers' Association | Christ College of Engineering, Thrissur

This repository contains the complete codebase for the **DELTA** student association website at Christ College of Engineering. 

```
Website - DELTA CCE/
 ├─ frontend/                   # React.js application
 │   ├─ src/                    # Source files (components, pages, routing)
 │   ├─ public/                 # Static templates
 │   ├─ tailwind.config.js      # Central design palette configuration
 │   ├─ package.json            # Node configurations
 │   └─ README.md               # Specific frontend setup instructions
 └─ README.md                   # Repository entry point (This file)
```

---

## 🛠️ Design Metrics: "The Intelligent Grid"
The application uses a custom visual language structured with CSS variables and Tailwind extensions:
- **Light Theme**: Generous whitespace, asymmetric outlines, monospaced tech headers (`Space Mono` / `JetBrains Mono`), and clean body text (`Inter`).
- **Accent Lines & Interactive Canvas**: A canvas system dynamically traces mouse movement and connects nodes using signal orange overlays on a paper cream background.

## 🚀 Quick Setup

To run this project locally, ensure you have [Node.js](https://nodejs.org) installed and run the following commands:

```bash
# 1. Clone the repository (if not already done)
# 2. Enter the frontend workspace
cd frontend

# 3. Install packages
npm install

# 4. Fire up the developer server
npm start
```
The server will run at [http://localhost:3000](http://localhost:3000).
